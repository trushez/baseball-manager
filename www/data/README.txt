Player and club data

default.json is the game's data: every player and every club in one file. It is plain JSON, so you can edit
any name, stat, grade or contract and start a new game to see it. Keep a copy before you change it.

To use another data pack (for example the real players for a season), put its .json file in the Data packs
folder in Documents/Baseball Manager (the game makes it the first time it runs; Game Options, Save and load,
opens it). New Game lists it under Player data; picking it replaces all players and clubs. A game you have
already started always uses the pack it was started with, so keep that pack in the folder.

Edit a copy, not this file: the game's install folder is replaced when the game updates.
